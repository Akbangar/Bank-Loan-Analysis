# 🏦 Bank Loan Analysis

A complete data analytics project that analyzes bank loan data using **Microsoft Excel, MySQL, Power BI, and Tableau**. The project focuses on understanding customer behavior, loan distribution, repayment performance, and financial trends through data cleaning, SQL analysis, and interactive dashboards.

---

## 📌 Project Overview

Financial institutions handle large volumes of loan applications every day. Analyzing this data helps banks understand customer behavior, monitor loan performance, reduce financial risk, and make better business decisions.

In this project, two financial datasets (**Finance 1** and **Finance 2**) were cleaned, combined, and analyzed using multiple analytics tools. The final dashboards provide meaningful insights into loan trends, customer verification, home ownership, and repayment performance.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze year-wise loan distribution
- Compare verified and non-verified customer payments
- Study loan grades and sub-grades
- Analyze state-wise and month-wise loan performance
- Understand the relationship between home ownership and repayments
- Create interactive dashboards for business decision-making

# 🔍 Key Insights

- Loan amounts increased year by year.
- Verified customers contributed more to total repayments.
- Grade B and Grade C customers had higher revolving balances.
- Mortgage holders showed better repayment behavior.
- Some states contributed more significantly to overall loan distribution.
- Interactive dashboards made business monitoring faster and easier.

# 💡 Business Recommendations

- Focus more on verified customers to reduce loan default risk.
- Improve credit assessment for high-risk borrowers.

- Use analytics to support better business decisions.
